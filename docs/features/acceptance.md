# 能力验收矩阵（0.4.5）

证据等级：
- **离线合同**：fixture / Node 测试
- **只读线上**：真实会话只读 API
- **用户动作**：需在 MyGo 手动点按确认

## 已兑现

| 能力 | 证据 |
| --- | --- |
| 登录 / 登出 / QR / 安全验证 | 历史线上 + SDK helper |
| 首页多板块、发现、榜单、历史、导航 | 只读线上 + 0.4.2 UI |
| 四类搜索与游标分页 | 只读线上 |
| 喜欢 / 收藏专辑 / 最近播放 / 歌单详情 | 只读线上 |
| 情景电台 + 首曲封面 + stationNext | 只读线上 |
| 歌词（含翻译排序）/ 评论翻页 | 只读线上 |
| 发评论（`created_comment` + 作者回填） | 线上响应形态 + 离线合同；需用户再确认 UI |
| 喜欢/收藏歌单专辑/建歌单/加歌 | 离线合同 + 成功响应形态；需用户确认 |
| 重命名/删除歌单、移出歌曲 | 一次性真实探针 + 离线合同；需用户确认 |
| standard/high 播放准备、授权 FLAC 路径 | 离线合成 + 历史播放链路；桌面出声需用户确认 |
| 封面 CDN 模板 | 只读线上图片 200 |

## 明确不做 / blocked

| 能力 | 原因 |
| --- | --- |
| 专辑/艺人完整详情 | PC detail 路由 404 |
| 搜索建议 | sug/suggest 1000004 |
| 关注艺人 / 评论点赞 | 无可信 PC HTTP 映射 |
| 歌单重排 `movePlaylistTrack` | reorder 404 |
| shows / remotePlay / 直播视频 | 宿主或服务边界 |
| Hi-Res / 空间音频 | 无独立可验证权益档位 |
| 跨重启磁盘音频缓存 / 队列预取 | 隐私与 helper 生命周期未设计 |

## 用户本地仍需确认

1. 安装 `plugin-qishui-0.4.5.zip` 后 ⌘Q 重启，登录标识 `[汽水 0.4.5 SDK]`
2. 扬声器出声；若有无损权益，选 lossless 是否真正 FLAC
3. 主动：发评论、喜欢、建/改名/删歌单、加歌/移曲
