# 原生运行包需求

目标：在 macOS arm64 的 MyGo Music 0.1.22 中导入一个 ZIP 后，即可使用汽水登录、曲库和授权音频，不要求用户安装 Node/npm、Electron、FFmpeg 或汽水桌面版，不要求环境变量或安装脚本。

保持插件 ID `qishui`。保存现有源码快照与旧账号数据；可验证的旧 Cookie 迁移到新会话，失败则重新扫码。真实账号测试只读，不自动点赞、发评论、修改歌单或上报播放。

展示需求：首页以当前账号的真实推荐歌曲为首屏主卡，紧接猜你喜欢、熟悉、新鲜等持续播放入口，再展示情景模式和探索内容。听歌模式包含默认推荐，使用对应模式推荐歌曲的专辑封面，不把 `/feed/mode` 的小 Logo 放大为封面。浏览预览不推进播放队列、不上报播放。保留旧版的推荐重心和音乐封面。

采用 lane128/mygo-music-qishui v1.0.11 的宿主 JS + Go worker + C++ signer；只交付本机验证的 macOS arm64。当前宿主 0.1.22 作为最低版本；不承诺其他平台或所有官方 App 功能。官方服务的二次验证、权益与格式限制继续生效。

验收：完整 ZIP，无链接及旧依赖；包内原生程序在不含开发工具的 PATH 下工作；真实宿主安装、登录模拟及核心调用通过；真实账号请求单独记录结果，不能用模拟替代。
