# 原生版审查与验收

范围：macOS arm64 / MyGo Music 0.1.22。复用来源固定到
`5d1223734d33505bcc40a50064f836f34184eabd`，本地源码差异见 NOTICE 和实施记录。

0.5.1 修复实际安装目录缺少原生文件的问题，新增“构建源码 → MyGo 文件夹导入 →
安装后的离线签名”回归，覆盖原来只验证 ZIP 遗漏的安装路径。完整包和旧 Python
入口统一构建流程。此轮记录见 `.dist/validation-report-0.5.1.json`；
0.5.0 的原生/解码结果仅在二进制哈希一致时复用。

当前环境未安装桌面自动化驱动，窗口刷新与错误消失仍须在 MyGo 重新加载后确认；
不将 Go 宿主集成冒烟等同于桌面窗口验收。

推荐展示修复的代码、只读服务、原生 UI 渲染/点击和本机候选包验证，
集中记录于 `.dist/recommendation-report.json`。UI 图由 MyGo 自身 ui.NewTester
生成，使用实际插件页面结构、匿名歌曲文字和官方公共专辑图，覆盖 1000/1440
窗口宽度及明暗主题；不代表操作了当前桌面窗口。个性推荐、模式封面与连续播放
入口分别验证，原生音频和 SDK 未改动且哈希保持一致时复用已有验收。

迁移、旧导航、上游便携 JS 及 Go 测试已运行。Go worker race 和
不含 Node/FFmpeg 的子进程 PATH 下的原生签名/音频 IPC 已运行。
签名只接受固定 3.7.0 的 x-helios/x-medusa，不使用旧版“任意 x-*”规则。

最终交付 ZIP 的文件数、字节数、SHA-256、宿主安装/调用及真实只读服务验证，
统一记录在构建机 `.dist/validation-report.json`，详细脱敏日志同目录保存。
测试通过不等于真实扫码或音频设备试听通过；各层结果以该报告分别记录。

真实服务已验证：旧会话由服务确认并迁移；固定 3.7.0 签名用于首页、
发现、榜单和历史读取；搜索返回 20 条。原混合发现响应约 1.66 MB，
已用 8 MiB 有界预算修复，边界测试覆盖恰好上限和超过一字节。
一首授权 M4A 为 9488766 字节，MyGo 自身解码器完整解码到 EOF：
44100 Hz、12865425 帧、PCM 有效且非静音。未做播放记录上报。
新扫码的人工确认和实际扬声器试听仍待用户执行。

ASan 因 Apple clang 17 / macOS 26.4 初始化自锁未完成，
证据见 `.dist/signer-boundary.sample.txt` 和
https://github.com/llvm/llvm-project/issues/200447 。
使用显式 UBSan 路径执行同一 C++ 边界集合，原生生产编译参数未改变。

不进行真实账号写操作。未验证其他平台；
服务端额外验证、账号权益和受限音频格式仍可能需要用户按提示处理。

## 0.5.2 发布

用户已确认推荐界面修复并授权发布。范围包含原生运行、完整安装与推荐展示，
目标为 macOS arm64 / MyGo Music 0.1.22+。原生组件、SDK 和生成 JS 与已验证候选
保持一致；只同步根 manifest、package/lock 版本和当前说明。复用源码
318 通过 / 11 可选跳过、Go race、UBSan、真实授权音频解码及原生 UI 五轮结果。
正式 ZIP 重新核验组件、许可证、源码一致性，并执行宿主安装与关键调用检查；
发布后的下载哈希及下载包安装结果记录在 `.dist/release-0.5.2.json`。
完整新扫码和扬声器试听仍为人工待验收项，不据此扩大已验证范围。
