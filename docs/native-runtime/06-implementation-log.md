# 实施记录

- 旧工作区源码完整快照保存于构建机 `.dist/rollback-source-0.4.6.tar.gz`；不提交、清理或覆盖旧账号目录。
- 固定上游 v1.0.11，保留全部对应源码；生产包使用上游白名单加本地两个便携适配器。
- 新迁移回归先验证缺失行为，再实现：账户验证后提交、过期标记、网络重试、退出与迟到响应保护。
- 原 discover/charts/history 导航通过共享 Catalog、签名器与 DTO mapper 接回。首页使用新版探索布局。
- 根 manifest 0.5.0，保留 qishui；最低宿主 0.1.22；进程权限缩小到包内 worker。
- 官方 3.7.0 归档与原生 pair SHA-256 均核验；Go/C++ 从本次源码编译，不使用上游预编译 worker 或旧缓存。
- Apple clang 17 的 ASan 在系统 dyld 初始化中自锁，尚未进入测试 main。采样与 LLVM issue #200447 相符。validator 增加显式 `--ubsan-only`，准确区分已运行 UBSan 与未运行 ASan，不改生产 signer。
- 宿主集成使用 Go overlay，参考夹具仅适配插件 ID 和旧导航的空请求体；不修改 MyGo checkout。
- 真实混合发现响应约 1.66 MB，超过上游为新版探索设的 1 MiB 预算；发现接口调整至与历史相同的 8 MiB，新增恰好 8 MiB 通过、超过一字节拒绝的回归。
- 收尾审查补齐新会话过期场景，过期标记同样阻止旧账号 Cookie 被恢复。
- 只读实测：现有账号验证、首页、发现 13 节、榜单 3 节、搜索 20 条，以及 9488766 字节的授权 M4A；MyGo 解码到 EOF，44100 Hz / 12865425 帧。测试仅用临时数据，原 storage 哈希保持一致，没有播放上报或其他真实账号写入。

## 0.5.1 安装修复

- 用户截图显示已授权但仍报启动错误。检查实际安装目录发现它含源码、测试和开发依赖，却无 bin/runtime，与完整 ZIP 不一致。先从已核验 ZIP 补回缺失的 7 个文件，保留其余内容及账号。
- 通过实际 MyGo 文件夹导入复现同样缺失；`npm run build` 改为同时生成原生运行目录，打包也同步相同产物回根目录。原生输出不提交。
- 抽出共享 build-runtime 构建配方；旧 Python 入口对原生 manifest 委托同一打包器，保留旧非原生包兼容。
- ENOENT 与权限失败分开报错。增加真实文件夹安装和启动诊断回归。

## 推荐展示修复

- 原生迁移带入了上游探索优先首页和模式 Logo 大图，偏离旧版个性推荐与音乐封面约定。回归先复现首页没有推荐主卡、模式图片来源错误。
- 恢复真实推荐主卡、猜你喜欢/熟悉/新鲜持续播放入口，情景与探索置后。模式封面独立预览相应 feed，不使用 Logo、不推进实际播放会话；账号内有界缓存避免重复请求。

- 使用实际插件 DTO、匿名示例歌曲文字及官方公共专辑图进行宿主原生明暗主题渲染和点击验收，证据集中于 `.build/recommendation-ui/`、`.dist/recommendation-*.log`。
